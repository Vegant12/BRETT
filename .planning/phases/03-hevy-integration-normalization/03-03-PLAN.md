   _PARENTHETICAL = re.compile(r"\s*\([^)]*\)\s*$")

   def normalize_title(title: str) -> str:
       """Reduce a Hevy exercise title to a stable lookup key.

   ```python
   def derive_assignments(
       *,
       template_id: str,
       title: str,
       primary_muscle_group: str | None,
       secondary_muscle_groups: Sequence[str],
   ) -> list[MuscleAssignment]:
       """Resolve one Hevy exercise template to canonical (muscle, role, source) triples.

       Order of authority:
         1. CURATED_BY_TEMPLATE_ID -- replaces everything, source='curated'
         2. the title split tables for `shoulders` / `abdominals` -- source='curated'
         3. the mechanical Hevy translation -- source='hevy'
         4. nothing (D-03 unmapped) -- NEVER an exception

       Direct beats indirect: if a group is reachable both ways, it appears once as direct.
       """
   ```
   Implementation rules, exactly:
   - If `template_id in CURATED_BY_TEMPLATE_ID`: return
     `[MuscleAssignment(g, r, MappingSource.CURATED) for g, r in CURATED_BY_TEMPLATE_ID[template_id]]`.
   - Otherwise build an ordered list of `(hevy_value, role)`: `(primary_muscle_group, DIRECT)` if
     it is not None, then `(v, INDIRECT)` for each `v` in `secondary_muscle_groups`.
   - For each pair, expand via a private `_expand(hevy_value, role, key)` helper where
     `key = normalize_title(title)`:
     - `"shoulders"` → `DELTOID_SPLIT_BY_TITLE.get(key)`; if absent and `role is INDIRECT`, use
       `SECONDARY_SHOULDERS_DEFAULT`; if absent and `role is DIRECT`, yield nothing.
       `source = MappingSource.CURATED`.
     - `"abdominals"` → `ABDOMINAL_SPLIT_BY_TITLE.get(key, ABDOMINAL_DEFAULT)`,
       `source = MappingSource.CURATED`.
     - otherwise → `translate_hevy_muscle_group(hevy_value)`; if `None`, yield nothing;
       else that group with `source = MappingSource.HEVY`.
   - Deduplicate into a `dict[CanonicalMuscleGroup, MuscleAssignment]` keyed by group, keeping
     the first occurrence; because directs are processed first, direct wins automatically.
     Return `list(result.values())`.

   The function must never raise on any input, including `primary_muscle_group=None`,
   an empty `secondary_muscle_groups`, an unknown enum value, or an empty title.
