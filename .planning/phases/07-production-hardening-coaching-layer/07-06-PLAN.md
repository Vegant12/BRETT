<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Developer workstation → Google Cloud | `gcloud` runs with the operator's credentials and can replace the live revision |
| Internet → deployed `/mcp` | `--allow-unauthenticated`; the anonymous verification rows are exactly what any internet client can do |
| Live service → committed record | Command output copied into `07-DEPLOY-RECORD.md` is public in git forever |
| Claude client ↔ WorkOS ↔ service | The OAuth consent from Phase 2 must survive the redeploy; a broken consent is an availability, not a confidentiality, problem |

## STRIDE Threat Register
