**Create `scripts/verify-restore.sql`.** A read-only per-table count plus an md5 content digest,
one `UNION ALL` arm per table, ordered deterministically. Row counts alone are weak — an
identical count over corrupted rows passes — which is why each arm carries a digest.

Header comment:

```sql
-- Restore-drill comparison query (D-02, ROADMAP Phase 7 criterion #3).
--
-- Run against BOTH the production branch and a branch created from a past
-- timestamp, then `diff` the two outputs. Identical output is the proof that the
-- restore lost nothing.
--
-- A count alone is not proof: an identical count over corrupted rows passes. Each
-- arm therefore carries an md5 over a deterministically ORDERED aggregate of a
-- stable key. Drop the ORDER BY and two identical databases produce different
-- digests, because string_agg has no defined order without one.
--
-- READ ONLY, and deliberately so: it is run by hand, as an operator, against real
-- health data. backend/tests/test_verify_restore_sql.py fails the fast suite if a
-- write verb, an unordered aggregate, a connection string, or a newly mapped table
-- missing from this file ever appears.
--
--   psql "$PROD_DSN"  -f scripts/verify-restore.sql > /tmp/prod.txt
--   psql "$DRILL_DSN" -f scripts/verify-restore.sql > /tmp/drill.txt
--   diff /tmp/prod.txt /tmp/drill.txt
```

Then one arm per table, all nine, e.g.:

```sql
  SELECT 'users' AS t, count(*) AS n,
         md5(string_agg(id::text, ',' ORDER BY id)) AS digest FROM users
UNION ALL
  SELECT 'workouts', count(*),
         md5(string_agg(external_id, ',' ORDER BY external_id)) FROM workouts
UNION ALL
  SELECT 'workout_exercises', count(*),
         md5(string_agg(id::text, ',' ORDER BY id)) FROM workout_exercises
UNION ALL
  SELECT 'workout_sets', count(*),
         md5(string_agg(id::text, ',' ORDER BY id)) FROM workout_sets
UNION ALL
  SELECT 'exercise_templates', count(*),
         md5(string_agg(external_id, ',' ORDER BY external_id)) FROM exercise_templates
UNION ALL
  SELECT 'exercise_muscles', count(*),
         md5(string_agg(id::text, ',' ORDER BY id)) FROM exercise_muscles
UNION ALL
  SELECT 'exercise_muscle_overrides', count(*),
         md5(string_agg(id::text, ',' ORDER BY id)) FROM exercise_muscle_overrides
UNION ALL
  SELECT 'body_measurements', count(*),
         md5(string_agg(measured_on::text, ',' ORDER BY measured_on)) FROM body_measurements
UNION ALL
  SELECT 'sync_state', count(*),
         md5(string_agg(resource || ':' || last_synced_at::text, ',' ORDER BY resource))
    FROM sync_state
ORDER BY 1;
```
