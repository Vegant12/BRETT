4. Add a property directly after the existing `async_database_url` property:

```python
    @property
    def mcp_allowed_hosts(self) -> list[str]:
        """Host header allowlist for the MCP transport's DNS-rebinding guard.

        A list in the environment is a comma-separated string by necessity, and
        an empty or whitespace-only entry would widen the allowlist by accident,
        so entries are stripped and empties dropped. With `transport_security`
        left at ``None`` the SDK silently allows only ``127.0.0.1``/``localhost``
        and Render's real Host header returns ``421 Invalid Host header`` with no
        MCP-level error body (T-02-01, RESEARCH Pitfall 2).
        """
        return [h.strip() for h in self.mcp_allowed_hosts_raw.split(",") if h.strip()]
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| environment → process config | Untrusted-shaped strings (`MCP_ALLOWED_HOSTS`, `MCP_AUTH_SECRET`) enter the process and become security-relevant policy |
| process config → log pipeline | Config values flow into `secret_values()`, which decides what the structlog scrubber redacts |
| repo → version control | `.env.example` and `pyproject.toml` are committed; a live value here is a permanent leak |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Spoofing | `Settings.mcp_allowed_hosts` | mitigate | Property strips entries and drops empties, so `"a,,b"` cannot silently widen the allowlist; default is `localhost,127.0.0.1` (closed), never `*` |
| T-02-04 | Information Disclosure | `_SECRET_FIELDS` / log scrubber | mitigate | `mcp_auth_secret` stays in `_SECRET_FIELDS`; `test_mcp_config_is_not_secret` asserts the four public MCP values are absent from `secret_values()` so the scrubber neither under- nor over-redacts |
| T-02-10 | Information Disclosure | `.env.example`, `pyproject.toml` | mitigate | New `MCP_*` entries in `.env.example` are commented out with placeholder hostnames only; no token literal is written. Existing gitleaks pre-commit hook is the backstop |
| T-02-03 | Information Disclosure | `mcp_resource_url` | accept | The value is a public URL by design (it is published anonymously in the RFC 9728 metadata document). Threat is credential-in-URL, which this field structurally cannot carry since the token travels in the `Authorization` header only |
</threat_model>
