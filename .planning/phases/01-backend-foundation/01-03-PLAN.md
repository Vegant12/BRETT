<objective>
Deliver the database layer: SQLAlchemy 2.0 declarative models with UTC-enforced timestamps, the async Alembic migration environment, the initial schema and default-user seed migrations, and the test infrastructure that builds every test database from migrations.

Purpose: FOUND-02 requires migrations to be the sole authority over schema, with a working downgrade. FOUND-04 requires UTC storage enforced by the type system rather than convention — `DateTime(timezone=True)` is the mechanism. D-01/D-02 require the single v1 user to arrive via a data migration, so every later phase can assume it exists.

Output: `alembic upgrade head` on an empty database produces the `users` table plus one seeded row; `downgrade base` reverses it cleanly; and pytest gets a session-scoped migrated Postgres container.
</objective>

```python
import datetime as dt

from sqlalchemy import DateTime, MetaData, func
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column

# Named constraints make Alembic autogenerate diffs stable and downgrades reliable.
# Without this, autogenerated downgrades reference server-assigned constraint names and break.
NAMING_CONVENTION = {
    "ix": "ix_%(column_0_label)s",
    "uq": "uq_%(table_name)s_%(column_0_name)s",
    "ck": "ck_%(table_name)s_%(constraint_name)s",
    "fk": "fk_%(table_name)s_%(column_0_name)s_%(referred_table_name)s",
    "pk": "pk_%(table_name)s",
}


class Base(DeclarativeBase):
    metadata = MetaData(naming_convention=NAMING_CONVENTION)


class TimestampMixin:
    """FOUND-04: every timestamp is TIMESTAMPTZ. Never use bare DateTime()."""

    created_at: Mapped[dt.datetime] = mapped_column(
        DateTime(timezone=True), nullable=False, server_default=func.now()
    )
    updated_at: Mapped[dt.datetime] = mapped_column(
        DateTime(timezone=True), nullable=False, server_default=func.now(), onupdate=func.now()
    )
```
