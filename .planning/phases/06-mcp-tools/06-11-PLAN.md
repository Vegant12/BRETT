## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Tool body exception → SDK error channel → Claude | The verified leak channel: `mcp 2.0.0` returns `str(e)` verbatim and structlog never sees it |
| Configured secrets (`DATABASE_URL`, `HEVY_API_KEY`, `MCP_AUTH_SECRET`) → any tool response | The three values that must never cross |
| Claude-supplied exercise name → the answer Claude gives the user | A silently wrong exercise is an integrity failure with no error to notice |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-06-01 | Information Disclosure | the SDK changing its error handling so `@safe_tool`'s justification silently stops holding | mitigate | `test_a_raising_tool_would_leak_without_the_guard` asserts the leak channel is still open on a throwaway server; it failing is the signal to re-verify, not to relax the guard |
