## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP tool registry → Claude's tool list | What is advertised here is what Claude will call, including the read-only and destructive hints |
| Committed source under `app/mcp/` → runtime behaviour | The static guards are the only control that fires on the commit rather than after a deploy |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
