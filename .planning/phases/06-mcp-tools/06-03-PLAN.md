```python
async def recent_workout_summaries(
    session: AsyncSession, *, user_id: uuid.UUID, tz: str, limit: int
) -> list[WorkoutSummaryRow]:
```
One aggregate statement:
- `select(Workout.external_id, Workout.title, Workout.start_time, Workout.end_time, ...)`
  joined `Workout -> WorkoutExercise -> WorkoutSet` with `isouter=True` on both joins (a workout
  with no sets is still a workout and must still appear).
- `WHERE Workout.user_id == user_id, Workout.provider == PROVIDER_HEVY`
- Aggregates, all with the hard-set predicate applied via `case`, never via a WHERE filter (a
  WHERE would drop warm-up-only workouts entirely):
  - `exercise_count = func.count(distinct(WorkoutExercise.id))`
  - `hard_sets = func.count(distinct(case((and_(*hard_set_predicates()), WorkoutSet.id))))`
  - `tonnage_sets = func.count(case((and_(*hard_set_predicates(), WorkoutSet.weight_kg.is_not(None), WorkoutSet.reps.is_not(None)), 1)))`
  - `tonnage_kg = func.sum(case((and_(*hard_set_predicates()), WorkoutSet.weight_kg * WorkoutSet.reps)))` cast to `Numeric(12, 3)`
- `GROUP BY Workout.id, Workout.external_id, Workout.title, Workout.start_time, Workout.end_time`
- `ORDER BY Workout.start_time DESC, Workout.external_id DESC` — the tiebreak is not optional: two
  workouts can share a `start_time` and an unstable order makes a flaky test.
- `.limit(limit)`
Then in Python: `local_day = local_day(row.start_time, tz)` and
`duration_minutes = round((row.end_time - row.start_time).total_seconds() / 60)` as an `int`.
