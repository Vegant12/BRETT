**Private validator** — runs BEFORE any INSERT (16-RESEARCH.md Pattern 5: a `ValueError` raised
early is cheaper to reason about than a partial write the DB's unique constraint catches
afterwards):
```python
def _validate_rating_coverage(ratings: Sequence[RatingEntry]) -> None:
    """D-07: exactly one entry per CanonicalMuscleGroup, each a level XOR a reason.

    Raises `ValueError` naming the offending groups. The database's own constraints
    (`uq_physique_ratings_observation_id_muscle_group`, `ck_physique_ratings_rating_xor_not_assessable`)
    are the backstop for any writer that bypasses this module -- not the first line of defence
    for this one, which would leave a half-written observation to clean up.
    """
```
It must check, in this order:
1. duplicates — `ValueError(f"physique observation has duplicate rating rows for: {sorted(...)}")`
2. missing groups — `ValueError(f"physique observation is missing rating rows for: {sorted(...)}")`
   (compare `{entry.muscle_group for entry in ratings}` against `set(CanonicalMuscleGroup)`;
   report the `.value` strings, sorted, so the message is stable)
3. per-entry XOR — for each entry, exactly one of `rating_level` / `not_assessable_reason` must
   be non-`None`; raise
   `ValueError(f"physique rating for {entry.muscle_group.value} must set exactly one of rating_level or not_assessable_reason")`
4. reason length — a `not_assessable_reason` longer than 160 characters raises `ValueError`
   naming the group and the cap, rather than letting asyncpg raise a truncation error mid-write

```python
# The five groups the Phase 15 spike actually rated, given real levels; every other group
# takes the Not Assessable path -- which is the ordinary case, not an edge case.
_SPIKE_RATED = {
    CanonicalMuscleGroup.CHEST: PhysiqueRatingLevel.DEVELOPED,
    CanonicalMuscleGroup.LATS: PhysiqueRatingLevel.EMERGING,
    CanonicalMuscleGroup.BICEPS: PhysiqueRatingLevel.DEVELOPED,
    CanonicalMuscleGroup.TRICEPS: PhysiqueRatingLevel.EMERGING,
    CanonicalMuscleGroup.ABS: PhysiqueRatingLevel.MINIMAL,
}


def _full_rating_set(
    *, omit: CanonicalMuscleGroup | None = None, duplicate: CanonicalMuscleGroup | None = None
) -> list[RatingEntry]:
    """All 19 canonical groups. `omit`/`duplicate` construct the two invalid inputs."""
    entries = [
        RatingEntry(muscle_group=group, rating_level=_SPIKE_RATED[group])
        if group in _SPIKE_RATED
        else RatingEntry(
            muscle_group=group,
            not_assessable_reason="No photo angle in this set shows the group.",
        )
        for group in CanonicalMuscleGroup
        if group is not omit
    ]
    if duplicate is not None:
        entries.append(
            RatingEntry(muscle_group=duplicate, rating_level=PhysiqueRatingLevel.MINIMAL)
        )
    return entries
```
