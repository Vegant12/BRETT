Ship RPT-01 and RPT-02 as two MCP tools.

Purpose: this is the phase's headline deliverable — ROADMAP success criterion #3 is "one tool
call returns a complete weekly report... and another does the same for a month, both inside the
measured latency and response-size budgets."

`fitness_get_training_summary` is the model this copies, and CONTEXT.md names it as such: one
read-only transaction around every composed call, a `_degraded_*` factory for `safe_tool`, and
verbatim-echoed disclaimer fields. D-02 adds the shape: reuse that tool's selected-field spine
and add NARROW extras — PR and plateau highlights, a body-measurement summary, a nutrition
summary, activity, and active-program context. Not full composition of every analytics result.

D-14 adds the one asymmetry: the MONTHLY response carries a `narrative` markdown string; the
weekly one does not.

Output: two response models, one tool module, two `MAX_REPORT_*` caps, two registrations, four
guard updates, two coaching-doc rows, and two measured budgets.

    @safe_tool(degraded=_degraded_weekly)
    async def fitness_get_weekly_report(ctx: Context[AppContext]) -> WeeklyReportResponse:
        """This week's complete picture in one call: Monday-to-today training volume and
        per-muscle work, personal records set this week, exercises that have stalled, waist and
        body-fat movement, nutrition and activity averages, the active training program, and the
        current recomposition verdict with its disclaimer."""
        user = resolve_user_id(ctx)
        async with read_only_session(ctx) as session:
            report = await compose_report(session, user_id=user, period=ReportPeriod.WEEKLY)
        return WeeklyReportResponse(**_report_body_fields(report))

    @safe_tool(degraded=_degraded_monthly)
    async def fitness_get_monthly_report(ctx: Context[AppContext]) -> MonthlyReportResponse:
        """This calendar month's complete picture in one call -- the same sections as the weekly
        report over a longer window -- plus a markdown narrative restating the same figures as
        prose."""
        user = resolve_user_id(ctx)
        async with read_only_session(ctx) as session:
            report = await compose_report(session, user_id=user, period=ReportPeriod.MONTHLY)
        return MonthlyReportResponse(**_report_body_fields(report), narrative=build_narrative(report))
