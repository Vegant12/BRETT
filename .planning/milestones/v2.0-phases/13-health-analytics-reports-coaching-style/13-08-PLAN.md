**Docstring** must state:
* D-14: a markdown narrative for the monthly report, generated by a DETERMINISTIC template, not
  free-form or AI-authored text. It restates the same composed data already present in the
  structured fields and introduces nothing.
* It is PURE and synchronous — takes the already-composed result, issues no query, and is
  therefore testable with no container, exactly like `backfill.py::format_summary`.
* No template engine. `grep -rln "jinja\|Template" backend/app/` finds nothing relevant, and a
  dependency for eight f-strings would be a dependency in the critical path of health data.
* D-03, restated at the point where it is easiest to violate: NO recommendation language. Not
  "you should", not "consider adding", not "try". Every line is a restatement of a number or a
  label the structured fields already carry. `test_analytics_reports.py` asserts this with a
  banned-token scan, because this is a rule a well-meaning future edit will break.
* `report.recomposition.disclaimer` travels VERBATIM. `RecompositionResult`'s own docstring calls
  it "a REQUIRED FIELD, not documentation"; a narrative that paraphrased it would be exactly the
  serialization change that docstring anticipates.

D-03's "no backend-computed recommendations" is enforced by three tests rather than by a comment. |
| T-13-37 | Information Disclosure | Narrative contents | mitigate | The narrative reads only `ReportResult` fields, all of which are already destined for the wire.
