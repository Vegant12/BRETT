fallback is `users.created_at` converted to the user's own local day: deterministic (a stored
value, not `CURRENT_DATE`), so replaying migrations on the same database yields the same row.
`gen_random_uuid()` is a PostgreSQL 13+ builtin; the test container is `postgres:18-alpine` and
production is Neon, so no `pgcrypto` extension is required.
